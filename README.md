# HelloMate Android releases

This repository is reserved for HelloMate release metadata and approved Android binaries. It does not contain application source, account data, credentials or signing keys.

**Public Beta status: not published.** There is currently no approved public APK download or public messaging service linked here.

Future releases will provide a directly downloadable signed `.apk`, version/build number, SHA-256, file size, supported Android versions/architectures, signing certificate fingerprint and source provenance. Public downloads will not require GitHub login.

Publication requires reviewed source, successful required checks, a persistent Owner signing identity, a verified HTTPS messaging backend and anonymous download verification. Development APKs and placeholder/localhost backends are not advertised as a public Beta.

HelloMate is proprietary software. No license to application source is granted by this binary distribution repository. Product terms and Beta limitations will accompany an approved release.
